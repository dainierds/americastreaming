# AMERICA Streaming

Sitio web moderno y profesional para servicio de streaming de **series, películas y canales de TV en vivo** con calidad 4K Ultra HD.

## 🚀 Características
- **Portada cinematográfica** con reproductor interactivo y demostración de video en vivo.
- **Secciones en blanco puro** al hacer scroll con animaciones AOS (Animate On Scroll).
- **Catálogo interactivo** con filtrado en tiempo real (Series, Películas, Canales en Vivo).
- **Tabla de precios** con conversor de moneda (Pesos Argentinos ARS / Dólares USD).
- **Guía de canales EPG** y monitor de red de transmisión CDN.
- **Preguntas frecuentes (FAQ)** y testimonios.
- **Formulario de contacto** y modales para login y demo.

## 💻 Visualización
Simplemente abre `index.html` en cualquier navegador web moderno.
